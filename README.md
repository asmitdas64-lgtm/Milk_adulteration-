# Machine Learning for Predicting Food Adulteration

B.Tech Minor Project — MIT Bengaluru (Department of Computer Science & Engineering)  
**Authors:** Asmit Das, Suprathik Narendra, Nadia Cecil  
**Guide:** Dr. S. Vaishnavi  

Predicting food adulteration based on low-cost physicochemical parameters using supervised machine learning algorithms.

## Quickstart
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   pip install -e .
   ```
2. Run test suite:
   ```bash
   pytest -q
   ```
3. Run complete pipeline:
   ```bash
   python -m foodadult.cli all
   ```
